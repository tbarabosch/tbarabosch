# Thomas Barabosch (tbarabosch)

Security engineer and researcher working across systems security, reverse engineering, threat research, incident response, detection engineering, and security automation. I like the point where careful technical analysis becomes useful: better detections, clearer investigations, stronger tools, and a deeper understanding of how systems fail.

I also explore how agentic and on-device AI can support repeatable security work without replacing deterministic analysis or engineering judgment.
